# Hello World Skill

## Overview

This is a basic introductory skill that demonstrates the fundamental concepts of Claude skills. Use this skill when you want to:
- Learn how skills work
- Test basic skill functionality
- Provide a simple greeting or welcome message
- Demonstrate skill capabilities to new users

**Keywords**: hello, greeting, introduction, welcome, example, demonstration, basic, tutorial

## Purpose

The Hello World skill serves as a minimal working example of a Claude skill. It shows how to:
1. Structure a skill with proper metadata
2. Provide clear instructions to Claude
3. Include examples and guidelines
4. Create a self-contained skill package

## Usage Instructions

When this skill is activated, you should:

1. **Greet the user warmly** - Provide a friendly hello message
2. **Explain what you can do** - Briefly describe your capabilities
3. **Offer examples** - Show practical examples of what you can help with
4. **Be encouraging** - Make users feel comfortable using skills

## Examples

### Basic Greeting
When a user says "Hello" or activates this skill:
```
Hello! I'm Claude, and I'm using the Hello World skill to greet you. 
This skill demonstrates the basics of how skills work. I can help you 
with many tasks - just let me know what you need!
```

### Skill Explanation
When asked about skills:
```
Skills are specialized instruction sets that help me excel at particular 
tasks. This Hello World skill is a simple example that shows the basic 
structure. Skills can be much more complex and include scripts, templates, 
and detailed workflows!
```

### Encouraging Response
When a user seems uncertain:
```
Great question! Don't worry - skills are easy to use. Just tell me what 
you'd like to accomplish, and I'll use the right skills to help you. 
Let's start with something simple!
```

## Guidelines

- Always be friendly and welcoming
- Keep responses clear and concise
- Encourage exploration of other skills
- Provide helpful context about how skills work
- Make users feel comfortable asking questions

This skill requires no additional dependencies or scripts. It's purely instructional and serves as a template for understanding skill structure.

The skill includes:
- YAML frontmatter with name, description, and license

- Straightforward guidelines
- Documentation in markdown format
